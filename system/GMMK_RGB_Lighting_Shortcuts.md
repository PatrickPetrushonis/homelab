# GMMK RGB Lighting Shortcuts
 
## LED Effects (Change Modes)
 
| Shortcut | Effect |
|----------|--------|
| **FN + INS** | Breath (RGB breathing / Single color breathing / Solid single color) |
| **FN + DEL** | Wave #1 (Wave with fade / Wave with less fade / Circular wave) |
| **FN + HOME** | Touch (Ripple from keypresses / Keys light and fade / Row spreads) |
| **FN + PGUP** | Drawing (Heartbeat / Kamehameha / Matrix) |
| **FN + END** | K-Effect (Random fade / Random on/off / Row fade) |
| **FN + PGDN** | Wave #2 (Bouncing wave / Solid color / Waves meet in middle) |
 
*Note: Each effect has 3 sub-variations that cycle when you press the hotkey again*
 
## LED Controls
 
| Shortcut | Function |
|----------|----------|
| **FN + ↑** | Brightness up |
| **FN + ↓** | Brightness down |
| **FN + →** | Speed up |
| **FN + ←** | Speed down |
| **FN + =** | Cycle through colors (if current effect supports it) |
| **FN + -** | Change effect direction |
| **FN + ESC** | Turn LEDs off |
 
## Other Shortcuts
 
| Shortcut | Function |
|----------|----------|
| **FN + F7** | Play/Pause |
| **FN + F9** | Mute |
| **FN + F10** | Volume Down |
| **FN + F11** | Volume Up |
| **FN + ESC then F1 + F3 + F5** (Hold 10s) | Factory Reset |
